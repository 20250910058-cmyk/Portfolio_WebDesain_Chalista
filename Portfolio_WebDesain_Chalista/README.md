# Portfolio Web Desain — Chalista Erika Putri

## Isi folder
- `index.html` — halaman utama portofolio.
- `style.css` — desain dan tata letak.
- `script.js` — data jadwal semester 1–3 dan navigasi mobile.
- `asset/` — tempat foto, gambar, dan dokumen pendukung.
- `praktikum/`, `tugas-teori/`, `laporan-praktikum/` — tempat mengorganisasi tugas.

## Cara menjalankan di VS Code
1. Ekstrak ZIP.
2. Buka folder `Portfolio_WebDesain_Chalista` di Visual Studio Code.
3. Pasang ekstensi Live Server jika belum ada.
4. Klik kanan `index.html` lalu pilih **Open with Live Server**.

## Yang perlu disesuaikan
1. Ganti teks email pada bagian Hubungi Saya.
2. Tambahkan foto profil ke `asset/images/`, lalu ubah elemen `.avatar` di `index.html` menjadi tag `<img>`.
3. Periksa kembali jadwal Semester 2 dan Semester 3.
4. Ganti baris Semester 1 di `script.js` setelah mendapatkan jadwal yang benar.
5. Ubah tautan pada bagian Tautan Cepat agar mengarah ke file/halaman tugas yang sudah benar-benar tersedia.

## Menambahkan tugas
- Simpan halaman tugas teori pada folder `tugas-teori/`.
- Simpan file kode praktikum pada folder `praktikum/`.
- Simpan dokumentasi laporan digital (jika diminta) pada folder `laporan-praktikum/`.
- Buat tautan ke setiap tugas dari bagian Tautan Cepat atau halaman indeks kategori.

## Publikasi GitHub Pages
1. Buat repository GitHub baru, misalnya `Portfolio_WebDesain_ChalistaErikaPutri`.
2. Salin seluruh isi folder ini ke repository tersebut.
3. Commit dan push ke branch `main`.
4. Buka **Settings → Pages** di repository.
5. Pada Build and deployment, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu Save.
7. Tunggu proses publikasi dan buka alamat GitHub Pages yang ditampilkan GitHub.

Catatan: jangan mengunggah data pribadi yang tidak perlu, kata sandi, atau dokumen yang hanya boleh diakses dosen/kelas.
